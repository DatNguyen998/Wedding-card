# 💌 Digital Wedding Card Gift

Welcome! This repository holds the code for a digital wedding card—a small, personal project built to celebrate a very special day.

---

### 👤 About the Author
My name is **Kent**. I work as a Business Analyst, usually spending my days thinking about enterprise systems and data workflows. I am naturally a bit shy with my words, so in my free time, I love using code to express my care for the people around me. I believe that technology doesn't always have to be about big businesses; sometimes, it can just be a quiet way to say congratulations.

---

### 🌱 The Purpose of This Project
The goal of this repository is very simple: **to blend learning with kindness.**
* **A Personal Gift:** I wanted to create a unique, interactive greeting card to celebrate a wedding—something memorable that the couple can look back on.
* **A Creative Sandbox:** This project gave me a wonderful excuse to practice my frontend web development skills. It challenged me to focus on the "feeling" of the UI, rather than just the function.

---

### 🛠️ How It Was Built
To make this digital gift come to life, I focused on a simple, expressive toolkit:
* **HTML5:** To structure the heartfelt messages, photos, and the layout of the card.
* **CSS3:** To style the card with elegant typography, soft animations, and a romantic aesthetic that fits a wedding theme.
* **Basic JavaScript:** To add small interactive touches, like the opening of an envelope or simple scrolling effects.
